# SEAM Product Language

This glossary defines the stable product terms used across SEAM plans,
licensing documents, packages, and operator surfaces. Architecture and
implementation details belong in their owning specifications.

## Canticle

The organization and product steward for SEAM and Ghost.

## SEAM

The source-available memory, knowledge, provenance, retrieval, and evidence
system. SEAM is a product, not the company and not an agent persona.

## SEAM Self-Host

The complete user-operated SEAM product. A self-host operator can run and host
SEAM without receiving a deliberately reduced memory engine.

## SEAM Suite

The self-host operator experience for SEAM. It includes the terminal control
center and independently openable browser dashboards for graphs, provenance,
and benchmark evidence.

## Managed SEAM

The Canticle-operated SEAM offering. Its public agent interface and WebUI form
the managed operator surface; managed operations are distinct from the
self-host product.

## Ghost

A SEAM agent. Ghost owns agent behavior, goals, planning, and tool use while
SEAM owns durable memory and evidence. Ghost is not a competing memory system
and is not the definition of SEAM.

## SeamSDK

The source-available in-process developer interface to full SEAM capabilities.
It is distinct from the open-source public HTTP client.

## seam-client

The open-source client for SEAM's public, opaque agent interface. It does not
define or expose the protected SEAM core.

## Public Agent Interface

The stable integration contract through which external agents remember,
recall, assemble context, and manage their own opaque memory handles.

## Operator Interface

The authenticated control interface used by SEAM operator surfaces. It may
expose administrative, graph, provenance, benchmark, and lifecycle operations
that do not belong in the public agent interface.

## Operator Surface

An interface used by a human operator to control or inspect SEAM. The TUI,
self-host dashboards, and managed WebUI are operator surfaces with different
delivery contexts.

## MIRL

SEAM's canonical memory intermediate representation. MIRL is source-available
protected core material and is not open source.

## SEAM-HS/1

SEAM's holographic-surface representation. HS/1 is source-available protected
core material and is not open source.

## Improvement Loop

SEAM's evidence-gated machinery for proposing, evaluating, promoting,
reverting, and learning changes to its representations and operating policies.
The Improvement Loop is source-available protected core material and is not
open source.

## Protected Core

The specially protected authored expression and implementation of MIRL,
SEAM-HS/1, and the Improvement Loop. The designation identifies the intended
license boundary; it does not claim ownership of abstract ideas, facts,
methods, or short names.

## Source-Available

Source code is available to inspect and use under a license that may restrict
competitive products. Source-available does not mean open source.

## Open Source

Software distributed under a license that permits use, modification, and
redistribution, including commercial and competitive use, subject to the
license terms. SEAM trademarks and branding are separate from copyright
permissions.

## Graph Dashboard

The browser-rendered operator surface for real knowledge, reasoning, and
provenance graphs. Terminal character art is not the graph product.

## Benchmark Glassbox

The operator surface for configuring benchmark runs, observing execution,
viewing real interactive charts, comparing results, and inspecting evidence.
It distinguishes free or local execution from explicitly approved paid
execution.
