# SEAM Prompt Library

[Back to the SEAM Wiki](../README.md)

These files are reusable, bounded task inputs for agents. A prompt is **not
implementation evidence**, current status, approval to spend money, or proof
that its requested work ran. Reconcile the current tree and controlling SOP
before reuse.
