# Grounded research acquisition roadmap

## Recorded decision

Track V records a planned, deferred SEAM acquisition layer for Hugging Face
and arXiv. Deterministic adapters will produce immutable, license-aware source
manifests and normalize accepted material through canonical RAW/MIRL ingest.
Hugging Face is CLI-first through `hf`; arXiv uses its official API or OAI-PMH
endpoint. Graph, vector, PACK, and library-stream views remain derived.

Ghost owns the Research Librarian agent, query planning, source-selection
reasons, and Codex/Claude/DeepSeek/local-model orchestration. SEAM does not run
that agent and does not create a second knowledge store. The SuperML reference
is workflow inspiration only; its plugin startup injection and MCP-backed
knowledge layer are not copied.

## Evidence boundary

This handoff changes roadmap, ledger, history, and continuity records only. It
does not implement an adapter, contact a provider, download or ingest a source,
create a corpus, train a model, run a benchmark, or change any Track S stage.

## Resume order

The active product boundary remains Track S: finish the unresolved S8
boundary-only SQL decision, then complete S9 qualification in dependency
order. Track V begins only after those retrieval gates and the H4 library
substrate are ready, with a frozen 5-10 item fixture before any bulk
acquisition. Coordinate its agent-facing contract with Ghost G3a without
moving canonical memory or provenance authority out of SEAM.
