# Contributing to private SEAM development

SEAM, MIRL, HS/1, and planned SEAM-U development in this repository is
proprietary. Access is limited to people expressly authorized by the Project
Owner. Read [LICENSE](LICENSE), [NOTICE](NOTICE), and
[COMMERCIAL_LICENSE.md](COMMERCIAL_LICENSE.md) before working with repository
material.

This repository is not accepting unsolicited external pull requests at the
pre-company boundary. Issues and technical discussion do not authorize source,
art, model, dataset, or documentation submissions for inclusion. External
contributions may open only after the receiving legal entity and
counsel-reviewed contributor agreement exist.

## Authorized scope

Repository access permits an Authorized Contributor to use and modify material
only for approved work on SEAM, within approved private systems. It does not
permit publication, external distribution, independent use, model-training
use, commercial use, or use in another project.

Do not copy source, specifications, schemas, tests, benchmarks, history,
research, prompts, private URLs, or implementation details into public issues,
public repositories, external assistants, datasets, or unapproved services.

## Contribution grant

An Authorized Contributor intentionally submitting material for inclusion
represents that they have the right to submit it and grants the contribution
rights stated in [LICENSE](LICENSE). A separate signed agreement controls if it
conflicts with those terms. Do not submit third-party material unless its
license and provenance have been reviewed and recorded.

## Product boundaries

Do not add an Apache or PolyForm notice to a private runtime file. A public
client, source-distributed SDK, or source-distributed Node belongs in its own
repository and release artifact, with automated boundary inspection. Exact
historical releases retain their original licenses; later private material does
not inherit them.

## Development protocol

Before changing the repository, read `AGENTS.md`, `PROJECT_STATUS.md`,
`REPO_LEDGER.md`, `HISTORY_INDEX.md`, `docs/CODE_LAYOUT.md`, and the current
handoff. Preserve unrelated changes, use a branch and pull request, run the
relevant tests, and complete SEAM's history, snapshot, handoff, continuity,
stream, and wiki gates.
