# A library built around evidence

SEAM reports connect a question, the work performed, and the evidence supporting the outcome. This Canticle Research library presents new investigations with their methods, results and limitations.

The library begins with work from September 12, 2026 onward. Earlier repository reports are not being imported.

## Three ways to read the work

**Research** develops a question or technical argument through methods, evidence, interpretation and limitations.

**Benchmark reports** describe an experiment's hypothesis, conditions, results and failures. A score only applies to its named dataset, models, evaluation method and budget.

**Test and qualification records** establish specific implementation properties at a named revision. Passing those checks does not establish a new benchmark score or deployment.

## A source for every report

Each page links to a pinned Git revision and provides a downloadable public edition. Separate SHA-256 digests identify the original source and the public edition. Runtime configuration and local execution details are omitted from the public edition; the repository's audit and testing records remain the sources of truth.

Once reports are published, context notes will identify corrections or later changes without silently rewriting the original record. New findings belong in successor reports.

Large datasets, private run records and credentials are outside this website. Reports can link to appropriate public artifacts and reproducibility material.
